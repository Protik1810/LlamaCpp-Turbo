# Security Policy

## Supported Versions

We actively provide security fixes and updates for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

If you discover a potential security vulnerability within **Llama.cpp Turbo Desktop**, please do **NOT** open a public issue on GitHub.

Instead, please send an email directly to the project maintainer:
- **Email**: `protik1810@gmail.com`
- **Subject**: `[SECURITY] Llama.cpp Turbo Desktop Vulnerability Report`

Please include:
1. A description of the vulnerability and its potential impact.
2. Step-by-step instructions or proof-of-concept code to reproduce the issue.
3. Your proposed fix or remediation suggestions (if available).

We will acknowledge receipt of your report within 48 hours and provide an estimated timeline for a patch.
